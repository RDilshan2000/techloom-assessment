Architecture & System Implementation

Overview of Section 02 E-Commerce Checkout & Payment System design principles.

Async SQLAlchemy & SQLite/Postgres

Built with Python FastAPI and async SQLAlchemy. Stock quantity updates happen atomically (`stock` vs `reserved_stock`) inside database transactions.

5-Minute Inventory Expiry Worker

Background worker scans unpaid `RESERVED` orders. Orders exceeding 5 minutes are set to `EXPIRED` and reserved items automatically return to available stock.

Payment Idempotency Keys

`POST /api/orders/{id}/pay` mandates `X-Idempotency-Key` or payload key. Duplicate double-click charges return cached transactions without double-billing or double-deducting stock.

Full Lifecycle & Restocking

Supports cancellation of unpaid reservations and refunds for paid orders. Refunding restores sold inventory straight back into available catalog stock.
